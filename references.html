Reference sites

Where to source data for this map — tool directories, model hubs, trending leaderboards, and the newsletters/podcasts that cover new launches early. Different from the Visualizations page, which lists VC-style landscape reports.

How to use these. Treat each as a feed. New tool shows up on Product Hunt or trending on GitHub → verify with Latent Space / Ben's Bites coverage → check if it's in Futurepedia or TAAFT → add to the relevant category page here.

There's An AI For That (TAAFT)

theresanaiforthat.com
DirectoryConsumer

What it is. The largest consumer-facing AI tool directory. Indexed by use case ("remove background," "summarize PDF," "generate voiceover") rather than by company.

Use as reference for. Long-tail consumer AI apps — the stuff that never makes it onto VC landscapes but powers creator/prosumer workflows.

theresanaiforthat.com

Futurepedia

futurepedia.io
DirectoryWell-tagged

What it is. Polished AI tool directory with clean categorization, pricing tiers, and ratings. More curated than TAAFT; fewer tools but higher signal.

Use as reference for. Quick competitor scans in a given category — e.g., "show me every AI writing tool with a free tier."

futurepedia.io

Product Hunt — AI

producthunt.com
Launch feedCommunity-voted

What it is. Daily product-launch feed with heavy AI concentration. The AI category alone gets dozens of launches a week, ranked by upvotes.

Use as reference for. New tools — if something launched this week, it's on PH before it's anywhere else. Good leading indicator of what's about to trend.

producthunt.com/categories/artificial-intelligence

Hugging Face

huggingface.co
Model hubCanonical

What it is. The GitHub of ML — hub for open-weights models, datasets, demo Spaces, and leaderboards. Trending tab is a real-time signal of which open models are getting traction.

Use as reference for. The open-weights model universe. If it isn't on Hugging Face, it's closed-source.

huggingface.coTrending models

GitHub Trending

github.com/trending
Dev signalReal-time

What it is. What developers are starring right now, filtered by language, timeframe, or topic. Search with topic:ai or topic:llm for the AI-specific slice.

Use as reference for. Open-source tools with dev momentum. Often the earliest signal — tools trend on GitHub weeks before they trend on Product Hunt.

github.com/trendingtopic:llm

Latent Space (swyx + Alessio)

latent.space
NewsletterPodcastInfra-deep

What it is. Shawn "swyx" Wang's AI engineering newsletter + podcast. The source for infra-deep AI coverage — interviews with founders before they're famous, technical dives into new tools.

Use as reference for. Context on why a tool matters. Less useful as a catalog, more useful as qualitative signal for which entries on the map deserve a bigger write-up.

latent.space

Ben's Bites

bensbites.com
NewsletterDaily

What it is. Daily AI-news newsletter aimed at a general audience. Broad coverage of launches, funding, features, and tool roundups. Beginner-friendly.

Use as reference for. Catching announcements you'd otherwise miss. Good breadth; less technical depth than Latent Space.

bensbites.com

TLDR AI

tldr.tech/ai
NewsletterDaily

What it is. The AI edition of the TLDR newsletter network. Short daily digest — headlines + one-paragraph summaries of papers, launches, and industry news.

Use as reference for. 5-minute-a-day coverage. Fastest way to stay baseline-informed. Redundant with Ben's Bites on most days; together they're near-exhaustive.

tldr.tech/ai

Artificial Analysis

artificialanalysis.ai
BenchmarksPricing

What it is. Independent benchmarks + pricing data for hosted LLMs. Compare GPT-5 / Claude / Gemini / DeepSeek / Qwen on throughput, latency, $/M tokens, quality — all in one chart.

Use as reference for. Hard numbers on the LLM Providers + Model Hosting categories. The only place to get apples-to-apples comparisons across providers.

artificialanalysis.ai

AI Industry Map

A guided tour of the tools, platforms, and companies that make up the generative-AI ecosystem — organized by what they actually do, not by buzzword. Click any category to see the top competitors, what sets each one apart, and how they connect to the rest.

Scope. This focuses on tools builders touch day-to-day (models, editors, agents, frameworks, infra). It does not cover consumer chatbots, image/video generators, or research labs as labs — those get their own page later.

Categories

LLM Providers

Foundation models — the "brains" everything else plugs into. OpenAI, Anthropic, Google, Meta, Mistral, xAI, Cohere, DeepSeek, Qwen.

9 competitors

AI Code Editors

IDEs where AI is stitched directly into your editor. Cursor, Windsurf, Antigravity, Copilot, Zed, JetBrains AI, Continue.

7 competitors

Autonomous Coding Agents

Agents that plan, edit, run tests, and ship — with less hand-holding. Claude Code, Devin, Jules, Codex, Gemini CLI, Amp, Cline, Aider, OpenHands, OpenClaude.

10 competitors

Agent Runtimes / Terminals

Terminals built to run AI coding agents in parallel. cmux (macOS), Wmux (Windows), Warp (cross-platform), Yaw, Windows Terminal.

5 competitors

App Builders

Prompt-to-app and prompt-to-prototype tools. v0, Bolt.new, Lovable, Replit Agent, Base44, Firebase Studio, Opal, Google AI Studio, Claude Design.

9 competitors

Agent Frameworks

Third-party libraries for orchestrating LLMs + tools. LangGraph, CrewAI, AutoGen, Pydantic AI, Mastra, LlamaIndex, Smolagents, Agno, Hermes, OpenClaw.

10 competitors

First-Party Agent SDKs

SDKs from the model makers themselves. Claude Agent SDK, OpenAI Agents SDK, Google ADK, Vercel AI SDK, Mistral Agents API.

5 competitors

MCP Ecosystem

Tools and registries built around the Model Context Protocol — the USB-C of AI. Smithery, MCP.so, Composio, Arcade, FastMCP.

5 competitors

Durable Execution

Infra for long-running, crash-proof agent workflows. Temporal, Inngest, Restate, Trigger.dev, Hatchet, DBOS.

6 competitors

Cloud AI Platforms

Hyperscalers' one-stop AI shops. AWS Bedrock, Azure AI Foundry, Google Vertex AI, Cloudflare AI.

4 competitors

Deployment Platforms

Where the front-end of your AI app actually lives. Vercel, Netlify, Railway, Render, Fly.io, Cloudflare Workers.

6 competitors

Vector Databases

Storage for embeddings — powers semantic search and RAG. Pinecone, Weaviate, Qdrant, Chroma, Milvus, pgvector, Turbopuffer.

7 competitors

AI Observability & Evals

Traces, evals, and dashboards for LLM apps. LangSmith, Langfuse, Helicone, Braintrust, Arize, PostHog LLM, Traceloop, W&B.

8 competitors

Model Hosting / Inference

Run open-source and custom models at scale. Replicate, Together, Fireworks, Modal, Baseten, Groq, Cerebras, RunPod.

8 competitors

Local Model Runners

Run LLMs on your own laptop or server. Ollama, LM Studio, llama.cpp, vLLM, MLX, Jan.

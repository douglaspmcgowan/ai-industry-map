Local Model Runners

Run LLMs on your own machine — laptop, desktop, workstation, or home server. Why: privacy, no API costs, offline use, and hackability. Split into end-user GUIs, CLI / developer tools, and production-grade inference engines.

Ollama

Ollama Inc.
Open sourceCLI + daemon

What it is. The de-facto "Docker for LLMs." `ollama run llama3` downloads and runs the model locally with a clean REST API. Ships models in a GGUF-based registry (`ollama.com/library`).

What sets it apart. Simplest dev experience in the category. Integrates with basically every local-LLM tool. macOS, Linux, Windows. The default "I want to run Llama locally" answer.

Connections. Built on llama.cpp internally. Works with Continue, Cline, Aider, OpenCode, LangChain, etc.

Usage
~100K+ GitHub stars; most-used local runner
Strength
Frictionless local LLM UX
ollama.comGitHub

LM Studio

LM Studio · closed-source client
GUIFree

What it is. Desktop GUI for running local LLMs. Browse Hugging Face models, download with a click, chat in a polished interface, expose as a local OpenAI-compatible API.

What sets it apart. Best GUI for non-CLI users. "Power Mode" exposes advanced settings for tuning. Free for personal use (closed-source).

Connections. Bundles llama.cpp + MLX runtimes. Works as a drop-in OpenAI API for other tools.

Usage
Millions of downloads; most-used GUI local runner
Niche
Non-CLI users; "just give me a chat UI for Llama"
lmstudio.ai

llama.cpp

Georgi Gerganov · open source
Open sourceC++

What it is. The foundational open-source C++ inference engine for Llama-family models. Created GGUF (the quantized model format used industry-wide). CPU + GPU, CUDA, Metal, Vulkan, everything.

What sets it apart. The layer underneath Ollama, LM Studio, Jan, and most other local runners. GGUF format set the industry standard for quantized weights.

Connections. Gerganov also makes whisper.cpp (speech-to-text) and ggml (the ML library powering both).

Usage
~70K+ GitHub stars; underneath most local runners
Strength
Portability + performance without a Python dependency
GitHub

vLLM

UC Berkeley (Woosuk Kwon et al.) · open source
Open sourceProduction

What it is. High-throughput inference engine for production. Introduced PagedAttention — a major innovation that doubled throughput for transformer serving. Python + CUDA.

What sets it apart. Production-grade batching + KV-cache management. What most "host your own Llama in prod" deployments actually run. Comparable to NVIDIA TensorRT-LLM and TGI.

Connections. Came out of Sky Computing Lab at UC Berkeley. Now a Linux Foundation project.

Usage
~40K GitHub stars; default OSS production engine
Niche
Production self-hosted inference at scale
docs.vllm.aiGitHub

MLX

Apple · open source
Open sourceApple Silicon

What it is. Apple's ML framework optimized for Apple Silicon (M-series chips). Like PyTorch but uses the unified-memory architecture that M-series provides. `mlx-lm` is the LLM sub-library.

What sets it apart. Fastest way to run big LLMs on a Mac — can fit a 70B model on a 128GB M3 Max / Ultra because RAM and VRAM are unified. Native Apple, open source.

Connections. Integrated into LM Studio's "MLX Engine" on Macs. Not useful on Linux/Windows.

Usage
Fast-growing in the Apple Silicon LLM community
Niche
Mac users running large local models
GitHubDocs

Jan

Jan (Menlo Research)
Open sourceGUI

What it is. Open-source LM Studio alternative. Desktop chat app for local LLMs with model browser, extensions, and OpenAI-compatible server.

What sets it apart. Fully open source where LM Studio is closed. Same polished UX. Appeals to users who want an LM-Studio-like experience but prefer auditable code.

Connections. Built on llama.cpp. Community-run fork culture, similar to early OBS.

Usage
~25K GitHub stars; growing OSS alternative
Niche
Open-source GUI for local LLMs

First-Party Agent SDKs

In 2024–2025, every major model provider shipped its own "just use us directly" SDK, partly as a reaction to third-party frameworks feeling heavy. These are thin, minimal wrappers with tool calling, conversation loops, and sometimes MCP support — all blessed by the company that also makes the model.

The PostHog take. These are the SDKs PostHog migrated to after their multi-year LangChain experiment. Lighter abstraction, fewer lock-in risks, and they track the underlying model's features (e.g., prompt caching, extended thinking) on day one.

Claude Agent SDK

Anthropic
Anthropic-nativeMCP built-in

What it is. The same engine that powers Claude Code, packaged as a library. Ships tools (read/write file, run command, web search), conversation loop, memory, permissions, hooks, and sub-agents out of the box. Python and TypeScript.

What sets it apart. Tightest integration with MCP (Anthropic's spec, but now industry-standard). Extended Thinking, prompt caching, computer use, and other Claude-specific features all first-class. Uses the exact code that runs Claude Code — no "SDK vs reality" drift.

Connections. Same team ships Claude Code and the Claude API. PostHog migrated to this from LangChain in late 2025.

Usage
Rapid uptake in 2025–2026; the default "just use Claude" framework
Docs
code.claude.com/docs/en/agent-sdk/overview
Overview GitHub (Python) GitHub (TS)

OpenAI Agents SDK (formerly Swarm)

OpenAI
OpenAI-nativePython + JS

What it is. OpenAI's official multi-agent orchestration library. Announced as "Swarm" (experimental) in 2024, promoted to "OpenAI Agents SDK" (production) in March 2025. Core primitives: Agents, Handoffs, Guardrails, Sessions.

What sets it apart. Multi-agent handoffs are first-class (vs. Claude's single-loop emphasis). Deep integration with the OpenAI Responses API, built-in tools (web search, file search, computer use, code interpreter), and tracing. Runs Voice + MCP natively.

Connections. Internally used to build ChatGPT agent mode and the OpenAI Codex cloud agent. Paired with OpenAI Traces UI for debugging.

Usage
Fast adoption among OpenAI-shop teams; alt to third-party frameworks for pure-OpenAI stacks
Philosophy
Multi-agent by default — explicit contrast with Anthropic's single-loop
Docs GitHub

Google Agent Development Kit (ADK)

Google · launched April 2025
Gemini-nativePython + Java

What it is. Google's official framework for building agents on Gemini. Primitives include Agent, Tool, Runner, Session. Integrates with Vertex AI Agent Engine for managed deployment.

What sets it apart. Ships an "A2A" (Agent-to-Agent) protocol alongside it — Google's answer to cross-framework agent communication. Works with any LLM via LiteLLM, not just Gemini (though Gemini is home).

Connections. Pairs with Vertex AI (managed agent hosting) and Google's AgentSpace product. Gemini-optimized but provider-agnostic.

Usage
Newest of the first-party SDKs; fast traction inside Google Cloud
Philosophy
Multi-agent + cross-vendor (A2A protocol)
Docs GitHub A2A protocol

Vercel AI SDK

Vercel
TypeScriptUI-aware

What it is. TypeScript SDK for building AI features in web apps. Unified API across OpenAI, Anthropic, Google, and 30+ other providers. Handles streaming, tool calling, structured outputs, and React-first UI streaming (RSC, useChat, useCompletion).

What sets it apart. Not strictly "first-party" to any model, but it's the default "model-agnostic thin wrapper" for the JS/TS world. Built-in React hooks. Tight Next.js / Vercel integration. "Agents" primitive added 2025.

Connections. Maintained by the same Vercel team behind Next.js, v0, and the Fluid / AI Gateway infra. Handles routing between providers via Vercel's AI Gateway.

Usage
De-facto TypeScript choice; 500K+ npm weekly downloads
Strength
Real-time UI streaming (React Server Components) is best-in-class
ai-sdk.dev GitHub

Mistral Agents API

Mistral
Mistral-native

What it is. Mistral's managed agents layer on top of their models. Ships built-in tools (code interpreter, web search, image gen, document library) and agent hand-offs. Announced May 2025.

What sets it apart. European sovereign-AI deployment option — enterprise customers worried about US / Chinese data policy. Batteries-included built-in tools mean you don't need to wire up your own search / sandboxes.

Connections. Pairs with Le Chat (consumer front-end) and Le Platforme (developer console). Works with Mistral Large, Codestral, etc.

Usage
Still smaller than OpenAI / Anthropic SDKs; concentrated in EU
Niche
EU-regulated, sovereign-AI workloads

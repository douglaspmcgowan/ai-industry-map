Vector Databases

Storage for embeddings — the numeric fingerprints of text/images/audio that power semantic search and retrieval-augmented generation (RAG). The field split in 2023 between "dedicated vector DBs" and "Postgres extensions that do it natively." Both are viable; the choice depends on scale and ops preference.

Where this sits in the stack. Your agent needs to "remember" a document corpus or knowledge base. You embed each chunk → store in a vector DB → query with a user-message embedding → get top-k chunks → stuff into the LLM prompt. That's RAG.

Pinecone

Pinecone · founded 2019 · CEO Edo Liberty
ManagedCategory leader

What it is. The original managed vector DB. Fully hosted, serverless mode, enterprise-grade. Launched the category in 2019 and defined the API most alternatives copied.

What sets it apart. Serverless pricing (pay per query, not per pod) makes it the easiest managed option for getting started. Largest enterprise customer base. Edo Liberty co-wrote the original vector-search research at Yahoo / AWS SageMaker.

Connections. Named in nearly every LangChain / LlamaIndex tutorial. Raised $100M Series B 2023.

Usage
Most-adopted managed vector DB
Strength
Managed, serverless, enterprise-ready
pinecone.ioDocs

Weaviate

Weaviate · Amsterdam
Open sourceMultimodal

What it is. Open-source vector DB with native multimodal support, built-in vectorization modules (you pass text, Weaviate embeds it), and hybrid BM25+vector search.

What sets it apart. Weaviate Cloud (hosted) + self-hostable in a container. Hybrid search out of the box. Strong European customer base.

Connections. Ecosystem partner with Cohere, OpenAI, Hugging Face for embedding models. Named in most RAG tutorials alongside Pinecone.

Usage
~11K GitHub stars; popular OSS choice
Strength
Multimodal + hybrid search + self-host option
weaviate.ioGitHub

Qdrant

Qdrant · Berlin
Open sourceRust

What it is. Rust-written vector DB with a focus on filtering + hybrid search. Self-hostable single binary or Qdrant Cloud.

What sets it apart. Fastest pure performance benchmarks in the category, thanks to Rust. Good payload-filtering (i.e. "vector search but only in documents written after 2024"). Free tier has no row cap.

Connections. Used by OpenAI (internal), GitHub Copilot, X (Grok memory), and many LLM apps via LangChain.

Usage
~22K GitHub stars; strong growth 2024–2025
Strength
Performance + filtering

Chroma

Chroma · founded by Jeff Huber & Anton Troynikov
Open sourceLocal-first

What it is. Lightweight Python-native vector DB. `pip install chromadb` and go. Designed for prototyping, notebooks, and small production workloads. Chroma Cloud adds managed hosting.

What sets it apart. Easiest onboarding of any vector DB — you can have a working RAG demo in 10 lines. Favorite for local dev + quick prototypes.

Connections. Default vector DB in most LangChain "getting started" tutorials. YC backed.

Usage
~17K GitHub stars; most-used for tutorials + prototypes
Strength
Simplicity, Python-native

Milvus (+ Zilliz Cloud)

Zilliz · founded 2017
Open sourceScale

What it is. Distributed, cloud-native vector DB designed for billion-scale collections. Open source; Zilliz Cloud is the managed version.

What sets it apart. Scale. Where Pinecone and Chroma handle millions of vectors, Milvus is built for billions — search engines, multimedia catalogs, recommendation systems.

Connections. Part of the LF AI & Data foundation. Powers vector search at Walmart, Nvidia, and others.

Usage
~30K GitHub stars; largest OSS vector DB by deployment count
Strength
Billion-vector scale + distributed architecture
milvus.ioGitHub

pgvector (Postgres)

Andrew Kane · open source
Open sourcePostgres

What it is. Postgres extension that adds vector types and HNSW / IVFFlat indexing. Turn any Postgres database into a vector DB with one `CREATE EXTENSION`.

What sets it apart. Reuses your existing Postgres — same backup, same auth, same ops, same transactions. The "don't need another database" pitch killed many dedicated vector-DB pitches in 2024–2025. Supabase and Neon ship it by default.

Connections. Default vector store in Supabase, Neon, Tembo, AWS RDS Postgres, and most managed-Postgres offerings.

Usage
Most-deployed vector storage globally (by virtue of Postgres ubiquity)
Strength
No new database, transactional, familiar SQL

Turbopuffer

founded by Simon Hørup Eskildsen (ex-Shopify)
ServerlessObject-storage-native

What it is. Serverless vector + full-text search built on S3-style object storage. Optimizes for cost at "many namespaces × few queries each" — the common pattern for per-user AI apps.

What sets it apart. Orders of magnitude cheaper than Pinecone when you have millions of small tenants. Used by Notion, Cursor, Linear for AI features. Darling of the AI-infra twitter crowd.

Connections. Used by Cursor for codebase indexing across all its users. Founder was a Shopify principal engineer.

Usage
Small but high-profile customer list; fast growth 2024–2025
Niche
Per-user / multi-tenant vector search at low cost

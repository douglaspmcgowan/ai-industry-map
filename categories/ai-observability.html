AI Observability & Evals

Traces, evaluations, and dashboards for LLM apps. Two overlapping jobs: observability (record what happened) and evals (test whether it was correct). PostHog's take: you need both, but looking at real traces beats running synthetic evals on day one.

Why this category exists. LLM apps are non-deterministic — the same input can produce different outputs. Without traces you can't diagnose bugs. Without evals you don't notice regressions. Every serious AI team ends up with one of these.

LangSmith

LangChain Inc.
ClosedTraces + evals

What it is. LangChain's observability + evals platform. Traces, human review, LLM-as-judge evals, dataset management, prompt playground.

What sets it apart. Works with any framework (not just LangChain). Market leader by usage. Tightest integration with LangGraph.

Connections. Often sold alongside LangGraph (they share SDK).

Usage
Largest managed LLM observability by revenue
Cost
Free tier; Plus $39/mo per seat; enterprise pricing
smith.langchain.comDocs

Langfuse

Langfuse · Berlin
Open sourceSelf-host

What it is. Open-source LangSmith. Traces, evals, prompt management, dataset management — all self-hostable. Also offers Langfuse Cloud.

What sets it apart. The default pick when you can't send prompts/outputs to a third-party SaaS (regulated industries, self-hosting preference). Generous free tier on Cloud.

Connections. Works with LangChain, LlamaIndex, Claude Agent SDK, OpenAI Agents SDK, any LLM.

Usage
~12K GitHub stars; leading OSS choice in category
Strength
Self-hostable; no data leaves your infra
langfuse.comGitHub

Helicone

Helicone · YC
Open sourceProxy-based

What it is. Proxy-based LLM observability — you point your OpenAI/Anthropic SDK at Helicone's URL and it logs everything. One-line integration.

What sets it apart. Lowest friction to install. Cost analytics + caching + rate limiting built in. Popular for quick-start observability.

Connections. Often paired with LangSmith or Langfuse — Helicone handles raw logging, the others handle evals.

Usage
Hundreds of thousands of developers; fast YC-era growth
Niche
Proxy-based "just-log-everything" simplicity
helicone.aiGitHub

Braintrust

Braintrust · founded by Ankur Goyal (ex-MotherDuck, ex-Figma)
Evals-first

What it is. Evals-centric platform. Write datasets as code, run LLM-as-judge graders, compare models side-by-side, integrate into CI. Traces and prompt management as supporting features.

What sets it apart. Best developer experience for evals-as-code. Strong typed SDKs. Used by Zapier, Vercel, and most "serious engineering culture" LLM teams.

Connections. Founders have MotherDuck + Figma backgrounds — product-engineering-heavy pedigree. Often cited alongside Promptfoo.

Usage
Fast-growing among technical teams; smaller user base than LangSmith, larger-contract focus
Niche
Evals-in-CI / TypeScript-native / engineering-rigor teams
braintrust.dev

Arize AI (+ Phoenix)

Arize · founded 2020
EnterprisePhoenix is OSS

What it is. Enterprise ML + LLM observability platform. Arize AX is the commercial product; Phoenix is the open-source core (notebook-friendly tracing + evals).

What sets it apart. Deep classic-ML roots — the only vendor covering both traditional ML monitoring and LLM observability in one platform. Popular at regulated-industry customers that need both.

Connections. Phoenix has ~4K GitHub stars; commonly used in Jupyter for one-off debugging.

Usage
Enterprise ML shops; less mindshare in startup AI than LangSmith
Strength
ML + LLM unified; regulated industries
arize.comPhoenix

PostHog LLM Analytics

PostHog
Open sourceProduct analytics

What it is. PostHog (product analytics) added LLM-specific analytics in 2024–2025. Combines traces with the product-analytics layer (session replays, funnel analysis, cohorts) — so you can correlate LLM quality with business metrics.

What sets it apart. The only option that unifies LLM observability with session replay and product analytics in one tool. PostHog's own AI team uses it for "Trace Hours" (watching real user traces).

Connections. PostHog also ships PostHog AI (an in-product agent) — eats its own dogfood.

Usage
PostHog has ~100K paying customers; LLM features adoption is the newest slice
Niche
Product + LLM observability unified
posthog.com/llm-observability

Promptfoo

acquired by OpenAI March 2026
Open sourceEvals + red-team

What it is. YAML-configured eval harness: define test cases, run across providers, get diffs. Also supports red-teaming / vulnerability scanning for agents. Acquired by OpenAI in March 2026 (the OSS project continues).

What sets it apart. Lowest-friction way to compare GPT vs Claude vs Gemini on the same prompts. Strong CI integration. Fireship favorite.

Connections. Now part of OpenAI's Frontier AI security platform. OSS tool still usable with any provider.

Usage
Tens of thousands of users; strong indie-dev adoption
Niche
Evals-as-YAML + red-teaming
promptfoo.devGitHub

Traceloop (OpenLLMetry)

Traceloop
Open sourceOpenTelemetry

What it is. OpenLLMetry is an open-source extension of OpenTelemetry for LLM apps. Traceloop is the managed dashboard built on top.

What sets it apart. Standards-based — emits OpenTelemetry spans. Works with any OTel-compatible backend (Datadog, Grafana, Honeycomb, etc.), not just Traceloop's own UI.

Connections. Part of CNCF / OpenTelemetry ecosystem. Preferred by orgs that already have big OTel investments.

Usage
Growing with OpenTelemetry adoption
Niche
OTel-shop AI observability

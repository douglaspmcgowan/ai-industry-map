Cloud AI Platforms

The hyperscalers' bundled AI offerings. Each one packages model hosting, agents, vector DBs, fine-tuning, and deployment into a single managed suite — convenient, enterprise-friendly, and deeply locked-in to their cloud.

The play. Enterprises with existing AWS/Azure/GCP contracts tend to use these by default because procurement, security review, and billing already exist. The trade-off: you pay a markup over running the models directly.

AWS Bedrock

Amazon · launched 2023
EnterpriseMulti-model

What it is. AWS's managed LLM service. Hosts Claude (Anthropic), Llama (Meta), Mistral, Cohere, Amazon Titan, Amazon Nova, Stability, and others — all through a single AWS API. Ships Bedrock Agents, Bedrock Knowledge Bases (RAG), and AgentCore for agent infra.

What sets it apart. Claude runs natively here (Amazon is Anthropic's largest investor). Deepest enterprise compliance surface — FedRAMP High, IL5, HIPAA, everything. Most neutral of the three clouds — doesn't push its own models as hard.

Connections. Amazon invested ~$8B in Anthropic; Claude is the flagship Bedrock model. Competes with Azure OpenAI and Vertex AI.

Usage
Dominant among AWS-first enterprises; grew ~5x in 2024
Strength
Widest model selection, including Claude and Llama natively
aws.amazon.com/bedrock Docs

Azure AI Foundry (ex-Azure OpenAI)

Microsoft
EnterpriseOpenAI-primary

What it is. Microsoft's unified AI platform (renamed from Azure OpenAI Service in late 2024). Primary home for OpenAI models outside openai.com itself, plus Llama, Mistral, DeepSeek, and Microsoft's own Phi models. Includes AI Foundry Agent Service, Azure AI Search (vector DB), and Copilot Studio.

What sets it apart. Exclusive early access to OpenAI models for Microsoft customers (Microsoft is OpenAI's exclusive cloud partner). Tightest integration with Microsoft 365, Teams, Dynamics, and Power Platform — if you live in the Microsoft world, this is the default.

Connections. OpenAI is the flagship provider. Copilot Studio is Microsoft's low-code agent builder on top. Microsoft has invested ~$13B in OpenAI.

Usage
Largest enterprise LLM deployment footprint globally; most Fortune 500 are on Azure AI
Strength
OpenAI exclusivity + M365 integration
azure.microsoft.com/ai-foundry Docs

Google Vertex AI

Google Cloud
EnterpriseGemini-first

What it is. Google Cloud's managed ML + GenAI platform. Hosts Gemini, Claude (via partnership), Llama, Mistral, and a Model Garden of 100+ open models. Ships Vertex AI Agent Builder, Agent Engine, Agent Garden, and the AI Applications suite.

What sets it apart. Only place (outside Anthropic directly) where you can get both Gemini and Claude through a unified enterprise contract. Deep integration with BigQuery — turning your warehouse into an AI substrate.

Connections. Google also invested in Anthropic (~$2B). Gemini 2.5 Pro is the flagship. Google's ADK (agent SDK) is the first-party framework that lives here.

Usage
Strong in data-heavy enterprises (BigQuery shops); smaller share than AWS/Azure overall
Strength
Gemini + Claude availability, BigQuery + Vertex AI joint story
cloud.google.com/vertex-ai Docs

Cloudflare Workers AI

Cloudflare
Edge-firstServerless

What it is. Cloudflare's edge AI platform. Runs open-weights models (Llama, Mistral, Qwen, etc.) on Cloudflare's global network at millisecond latencies. Ships Workers (compute), AI Gateway (model routing), Vectorize (vector DB), and Agents SDK.

What sets it apart. Lowest-latency inference anywhere thanks to edge deployment. Usage-based pricing with no idle cost — attractive vs. the hyperscalers for spiky workloads. Ecosystem plays well with Next.js / Hono / serverless stacks.

Connections. Co-creator with Anthropic of the WebBot Auth protocol for agent authentication. Primary host for OpenAI's own edge-latency demos. Browserbase and other cloud-browser tools often run on Cloudflare infra.

Usage
Millions of Workers developers; AI side growing fast in 2025
Niche
Edge / low-latency / serverless-first AI apps
developers.cloudflare.com/workers-ai Agents SDK

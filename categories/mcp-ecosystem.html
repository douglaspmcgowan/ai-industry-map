MCP Ecosystem

The Model Context Protocol is an open standard (originally from Anthropic, Nov 2024) that lets any AI agent talk to any tool. Think USB-C for AI tools. In 2025 it became the industry-default — OpenAI, Google, Microsoft, and most frameworks now speak MCP. This category is about the registries, hosts, and SDKs that grew around it.

MCP in one paragraph. An "MCP server" exposes tools (functions the AI can call), resources (data it can read), and prompts. An "MCP client" (Claude Desktop, Cursor, Windsurf, ChatGPT, etc.) connects to it over stdio (local) or HTTP (remote). Specs at modelcontextprotocol.io.

The MCP Spec + Reference Servers

Anthropic (original) · now multi-vendor stewardship
Open specIndustry standard

What it is. The protocol itself, plus Anthropic's reference MCP servers (file system, GitHub, Slack, Postgres, Puppeteer, etc.) in the modelcontextprotocol/servers repo.

What sets it apart. The spec is the whole ecosystem — everything else listed here piggybacks on it. Adoption by OpenAI, Google, Microsoft, and the open-source world in 2025 turned MCP into a genuine cross-vendor standard (rare in AI).

Connections. Launched by Anthropic. Now stewarded via an open working group. Huge reference-server library.

Usage
Supported by Claude Desktop, Cursor, Windsurf, Zed, ChatGPT Desktop, VS Code, and more

Smithery

Smithery · 2024
Registry + runtime

What it is. The most-used MCP server registry. Lets you discover, install, and even host MCP servers with one click — both local (stdio) and remote (HTTP).

What sets it apart. Hosted-server runtime (not just a directory) means MCP servers can run remotely without you setting up infra. Clean one-command installers for most clients.

Connections. Closest thing to an "npm for MCP." Works with Claude Desktop, Cursor, Windsurf, etc.

Usage
Thousands of MCP servers indexed; primary installer for MCP in the wild
Role
Registry + hosted runtime + install UX
smithery.ai GitHub

MCP.so

community-run
Directory

What it is. Community directory of MCP servers, clients, and resources. Includes install configs, stars, descriptions, and categories.

What sets it apart. Broader and more neutral than Smithery — lists servers that aren't hosted on Smithery's runtime. Good for browsing and benchmarking.

Connections. Free alternative to Smithery for discovery-only. Indexes any GitHub-hosted MCP server.

Usage
Thousands of servers listed; hundreds of thousands of monthly visits
Role
Pure directory / awesome-list-as-a-service

Composio

Composio · YC-backed
Tool platformEnterprise

What it is. Managed tool-integration platform with 250+ pre-built tool integrations (Gmail, Slack, Notion, Linear, etc.) that you can drop into any agent via MCP or native SDKs. Handles auth (OAuth flows), rate limits, and tool versioning.

What sets it apart. OAuth / auth is the hard part of agent-tool integrations — Composio takes on that burden. Works with LangChain, CrewAI, Claude Agent SDK, OpenAI Agents, etc., so you can use it regardless of framework.

Connections. Alternative category leader to Arcade. Popular with enterprise agent builders who need reliable SaaS integrations.

Usage
Used by thousands of agent projects; SOC 2 compliant
Role
"Zapier for agents" + auth manager

Arcade

Arcade (formerly Arcade AI)
Tool platformAuth-heavy

What it is. Another managed "tools + auth for agents" platform. Pre-built integrations + a framework for writing your own custom tools in Python, with OAuth handled for you.

What sets it apart. Developer-first SDK — writing a custom tool is one decorator away. Head-to-head competitor with Composio; the two often come up together.

Connections. MCP-compatible. Works with major agent frameworks.

Usage
Mid-size dev community; fast growth in 2025
Role
Similar to Composio; more custom-tooling-first
arcade.dev Docs

FastMCP

Jeremiah Lowin (Prefect) · open source
Open sourcePython

What it is. The most popular Python framework for building MCP servers. Decorator-based (like FastAPI) — you write tools as normal Python functions and FastMCP exposes them over MCP.

What sets it apart. Ergonomics — building an MCP server is typically <20 lines. Auth, sessions, and deployment helpers baked in. FastMCP 2.0 (2025) merged into the official modelcontextprotocol/python-sdk as its ergonomic layer.

Connections. Jeremiah Lowin also built Prefect (workflow engine). FastMCP is now effectively the default way to write MCP servers in Python.

Usage
Most community MCP servers are written with FastMCP
Role
"FastAPI for MCP"

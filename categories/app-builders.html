App Builders (Prompt-to-App)

Type a description, get a working web app. This category exploded in 2024–2025. The tools differ mainly on who the user is: designers (v0), non-engineers (Lovable, Base44), engineers wanting a sketch (Bolt.new), or existing Replit users (Replit Agent).

Vibe-coding. Andrej Karpathy coined "vibe coding" (Feb 2025) to describe this workflow — you don't even read the code, you just steer the vibe. Half the category is defined by this meme.

v0

Vercel · launched Oct 2023
React/Next.jsDesign-first

What it is. Vercel's prompt-to-UI tool. Describe a UI or paste a screenshot; get React + Tailwind + shadcn/ui code you can deploy to Vercel in one click. Has evolved from "generate a component" to "generate a full app."

What sets it apart. Tightest integration with the Next.js + Vercel stack — the apps you build actually deploy cleanly. Output is idiomatic, modern React that professional devs can continue editing. Has its own model family ("v0-1.5") tuned for UI code.

Connections. Vercel also makes the AI SDK and Next.js. Works seamlessly with shadcn/ui (Vercel's design system). Competes directly with Bolt.new and Lovable.

Usage
Millions of generations/month; a primary Vercel growth driver
Audience
Designers + front-end devs who already know Vercel
v0.app vercel.com (parent)

Bolt.new

StackBlitz · CEO Eric Simons
Full-stackIn-browser

What it is. A full-stack app builder running entirely in your browser. StackBlitz built "WebContainers" — Node.js in WASM — which lets Bolt run a real dev server + npm install in-browser, not on a remote VM. Users prompt, Bolt generates and runs a full app.

What sets it apart. No cloud VM = instant feedback loop, works offline-ish, no infrastructure cost per session. Went from $0 to $20M ARR in 2 months in late 2024 — one of the fastest SaaS ramps on record.

Connections. Built on StackBlitz's decade-old WebContainer tech. Deploys to Netlify, Cloudflare, Vercel. Heavy Claude user under the hood.

Usage
Hit $40M+ ARR in first ~6 months; millions of apps generated
Tech moat
WebContainers — the "Node-in-browser" nobody else has
bolt.new stackblitz.com (parent)

Lovable

Sweden · CEO Anton Osika
Non-dev friendlyEurope

What it is. "GPT-Engineer for everyone." Web-based app builder targeting non-developers; Supabase is the default backend. Launched November 2024 and reached $17M ARR in 3 months — fastest European SaaS ever.

What sets it apart. Best-in-class UX for non-technical founders. Clean integration with Supabase for auth + database. Aggressive social marketing made "built with Lovable" a meme on Twitter/X in 2025.

Connections. Originated from the GPT-Engineer open-source project (also by Anton Osika). Deep Supabase partnership. Uses Claude heavily.

Usage
$17M ARR in 3 months (Jan 2025); 500K+ users; ~$100M ARR by late 2025
Audience
Non-technical founders and solopreneurs
lovable.dev GPT-Engineer (origin)

Replit Agent

Replit · CEO Amjad Masad
Cloud IDEDeployed in-place

What it is. Replit's AI agent, launched 2024, now the front door to Replit. Describe an app; the agent scaffolds files, wires up a DB, and deploys to a live URL — all inside Replit's existing cloud IDE.

What sets it apart. Unique position: Replit already had the IDE + hosting + DB integrated, so Agent is "just add AI" on top of a working product. Supports Python, Node, Go, Rust, etc. — most general-purpose of the app builders. "Replit Bounties" lets you outsource Agent tasks to humans if they get stuck.

Connections. Replit predates the AI wave (founded 2016). Huge education user base. Uses Claude heavily.

Usage
~30M Replit users; Agent drove $100M+ ARR in 2024
Audience
Existing Replit users, students, multi-language builders
replit.com Agent docs

Firebase Studio

Google · evolved from "Project IDX"
Full-stackBeing sunset 2026

What it is. Google's prompt-to-app platform. Announced April 2025 (renaming Project IDX). Browser-based agentic dev environment that uses Gemini to scaffold full apps on Firebase + Google Cloud infra.

What sets it apart. Native access to Firebase Auth, Firestore, Cloud Functions, Hosting — everything a web app needs. Google-grade free tier. Gemini 2.5 Pro as the agent planner.

Status (April 2026). Google announced it is sunsetting Firebase Studio in favor of Antigravity + Google AI Studio's merged "full-stack vibe coding" pipeline. You can still publish existing Firebase-Studio apps from Antigravity or AI Studio.

Status
Sunsetting; use Antigravity + AI Studio instead
Legacy
Successor to Project IDX; relative short shelf life
firebase.google.com/studio

Google AI Studio

Google
Prompt + appGemini-native

What it is. Originally Google's prompt-playground for the Gemini API; in 2026 it merged with Antigravity to become a full-stack "vibe coding" experience. Prototype a prompt in the browser, then hand it off to Antigravity's autonomous agents to build the app around it.

What sets it apart. Tight seam between "play with the model" and "ship the app" — the handoff between prompt engineering and agent coding is smoother than any other tool. Free tier with Gemini 3.1 Pro preview access.

Connections. Now effectively the front door to Google's developer stack: AI Studio → Antigravity → deploy. Replaces much of what Firebase Studio did.

Status
Primary Google builder entry point as of 2026
Models
Gemini 3.1 Pro preview + earlier Gemini generations
aistudio.google.com Vibe-coding launch post

Claude Design

Anthropic Labs · launched April 17, 2026
Design-firstOpus 4.7

What it is. A "prompt-to-prototype" tool that outputs polished visual work rather than running code: designs, prototypes, slides, one-pagers. During onboarding, Claude reads your codebase + existing design files to build a design system (colors, typography, components) that every later project reuses automatically. Exports to PDF, shareable URL, PPTX, or Canva.

What sets it apart. Sits half-in the App Builders category: it makes visuals, not apps. But the codebase-aware design-system extraction is unique — other tools start from zero every time. Generates custom sliders tied to specific elements so non-designers can tweak visually. Figma's stock dropped 6.8% on announcement.

Connections. Powered by Claude Opus 4.7. Research preview for Claude Pro / Max / Team / Enterprise subscribers. Adjacent to v0 (design-first code) but orthogonal: v0 ships React; Claude Design ships pixels.

Category note
Design/prototype output, not app output — the closest existing fit on this map
Availability
Research preview (paid Claude plans only)
Launch post claude.ai

Base44

founded by Maor Shlomo · Israel · acquired by Wix 2025
Non-devAcquired

What it is. No-code AI app builder. Users describe an app in plain language; Base44 generates a working web app, auth, and DB. Acquired by Wix in mid-2025 for ~$80M after a ~$10M ARR ramp in months.

What sets it apart. Even more tuned for "non-developer founder" than Lovable. Also notable as the first prominent solo-founder AI app-builder exit, proving the category can produce huge outcomes.

Connections. Now part of Wix (site builder, ~300M users). Positioned as Wix's answer to the Lovable / Bolt wave.

Usage
~250K users at acquisition
Exit
~$80M to Wix, mid-2025
base44.com wix.com (parent)

Google Opal

Google Labs
No-codeExperiment

What it is. A no-code "AI mini-app builder" from Google Labs launched mid-2025. Lets you describe a small tool or workflow (image generator with specific styling, structured-output form, etc.) and get a shareable mini-app — somewhere between a ChatGPT GPT and a full web app.

What sets it apart. Sits at a lighter tier than Firebase Studio — simpler mental model, not trying to build a full app. Targets the "I just want a branded AI thing I can share" user.

Connections. Part of Google's 2025 AI builder stack (paired with Jules / Antigravity / Firebase Studio). Gemini-backed.

Usage
Early labs product; adoption still unclear
Positioning
"ChatGPT GPTs, but from Google"
opal.withgoogle.com

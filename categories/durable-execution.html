Durable Execution

Infrastructure for workflows that must survive crashes, restarts, and long waits. Agents often run for minutes or hours, hit rate limits, wait on human approval, or need to retry after a model outage. Durable-execution engines checkpoint every step so the workflow can resume exactly where it left off — even days later.

Why this matters for agents. A naive agent loop dies if the process crashes. Durable execution turns your agent into a workflow whose state is persisted every step, so you can survive deploys, restarts, and 24-hour "wait for human" pauses without losing a byte of context.

Temporal

Temporal Technologies · founded 2019 · CEO Maxim Fateev
Open sourceEnterprise

What it is. The category-defining durable-execution engine. Originally spun out of Uber's Cadence project. Workflows are code (Go, Java, Python, TS, .NET, Ruby, PHP) — every step is automatically checkpointed.

What sets it apart. Maturity — runs in production at Uber, Netflix, Stripe, Airbnb. Handles billions of executions. "Workflow as code" beats YAML DSLs for complex branching. Temporal Cloud is the hosted version.

Connections. OpenAI uses Temporal for some internal agent workflows. Many agent frameworks have Temporal adapters.

Usage
Fortune-500 heavy; largest durable-exec engine by deployment count
Strength
Ceiling is very high; handles massive scale and regulated workloads
temporal.io Docs GitHub

Inngest

founded by Dan Farrelly & Tony Holdstock-Brown · 2021
TypeScript-firstAgentKit

What it is. Developer-friendly durable execution designed for modern serverless/TS stacks. Event-triggered workflows, steps, and concurrency controls; runs on your own infra or Inngest Cloud. Ships "AgentKit" — purpose-built agent primitives on top.

What sets it apart. Much lighter onboarding than Temporal. Works beautifully with Next.js, Vercel, Supabase. Co-founder Dan Farrelly is one of the loudest voices arguing "durable execution is the missing layer for agents."

Connections. Popular in the Vercel / Next.js ecosystem. AgentKit is their answer to LangGraph-style orchestration but with durability built in.

Usage
Fast-growing; default durable-exec for many TS/serverless teams
Niche
Serverless + TypeScript + agents
inngest.com AgentKit GitHub

Restate

Restate · co-founded by Stephan Ewen (ex-Apache Flink)
Open sourceRust engine

What it is. Single-binary durable-execution engine written in Rust. Combines durable workflows, transactional state, and RPC into one system. Workflow SDKs in TypeScript, Java, Python, Kotlin, Go, Rust.

What sets it apart. Single binary — drop it on a box, done. No Kafka / Cassandra / separate databases needed (unlike Temporal's heavier footprint). Strongest "developer local-first" experience in the category.

Connections. Stephan Ewen was a co-founder of Apache Flink (stream processing). Restate is the team's second act — focused on the "operations" half of what Flink didn't quite nail.

Usage
Early but growing fast; popular in European engineering teams
Strength
Simplest ops footprint in the category
restate.dev GitHub

Trigger.dev

Trigger.dev · founded 2023
Open sourceTypeScript

What it is. Background jobs + durable workflows for TypeScript. Tasks run on Trigger's own infra or self-hosted. Specifically positioned around long-running AI tasks that exceed serverless function timeouts.

What sets it apart. AI-first positioning — "run your LLM task for 8 hours." Strong monitoring UI, retries, and concurrency keys. Generous free tier.

Connections. Popular in Next.js / Remix apps. Often used with OpenAI / Anthropic long-running tasks.

Usage
Growing fast; ~15K GitHub stars
Niche
TypeScript devs with long-running AI jobs
trigger.dev GitHub

Hatchet

Hatchet · YC-backed
Open sourcePostgres-based

What it is. Distributed task queue / workflow engine backed by Postgres. Sweet spot: more power than a raw job queue, less ceremony than Temporal.

What sets it apart. Postgres as the source of truth — easy ops, easy to understand. Python, TS, Go SDKs. Good fit for teams that already have a Postgres-centric stack.

Connections. Often described as "Temporal lite" or "Inngest but on your Postgres."

Usage
Smaller but growing; mid-size engineering teams
Niche
Postgres-first, self-hosted, no new infra
hatchet.run GitHub

DBOS

founded by Mike Stonebraker & Matei Zaharia
Open sourceResearch-grade

What it is. Durable-execution library where the OS is essentially Postgres. Founders are Turing-award-winner Mike Stonebraker (Postgres) and Matei Zaharia (Spark, Databricks). TypeScript and Python.

What sets it apart. Academic pedigree — based on the "DBOS" OS paper. "Exactly-once" durable workflow semantics in <100 lines of glue code. Aggressive simplicity: your workflow state IS a Postgres row.

Connections. Spun out of MIT / Stanford. Strong overlap with Restate and Hatchet philosophically (single-binary, Postgres-centric).

Usage
Early; strong traction among academic / research-inflected teams
Founders
Stonebraker (Postgres) + Zaharia (Spark) — unusual pedigree
dbos.dev GitHub

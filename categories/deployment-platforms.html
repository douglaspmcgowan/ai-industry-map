Deployment Platforms

Where the web-app half of your AI product actually runs. These aren't AI-specific — they just happen to host 90%+ of new AI apps because they're the modern default for web deployment.

Vercel

Vercel · CEO Guillermo Rauch
Next.jsAI-first

What it is. The deployment home for Next.js (which Vercel also makes). Handles serverless functions, edge compute, CDN, preview deploys, and now AI Gateway for routing LLM calls.

What sets it apart. Tightest dev loop — git push → live URL in seconds. Shipped v0 (prompt-to-UI) + AI SDK + AI Gateway as a full AI-dev stack. Used by most AI-native startups by default.

Connections. Makes Next.js, v0, AI SDK. Runs Claude Code's hosted web version. Primary deploy target for Bolt.new / Lovable / Replit outputs.

Usage
Millions of developers; dominant in JS/TS indie ecosystem
Strength
Fastest dev-to-prod for front-end + serverless
vercel.comDocs

Netlify

Netlify · CEO Mathias Biilmann
JAMstack

What it is. The original Jamstack platform. Static + serverless functions + forms + identity + edge functions. Pre-dates Vercel's current dominance; still strong in its core niche.

What sets it apart. Framework-agnostic (where Vercel leans Next.js-heavy). Strong Stripe-like pricing clarity. Popular default for Bolt.new deploys.

Connections. Ongoing fierce rivalry with Vercel. Acquired Gatsby in 2023.

Usage
~4M developers; strong in static-site / marketing-site world
Niche
Framework-agnostic Jamstack
netlify.comDocs

Railway

Railway · CEO Jake Cooper
PaaSIndie-friendly

What it is. Heroku-style PaaS. Deploy any language / framework / database from a git repo; Railway handles the infra. No "only Next.js" bias like Vercel.

What sets it apart. Clean UX, fair pricing, polyglot out of the box — Python, Node, Go, Rust, Postgres, Redis, all one-click. Popular for AI back-ends and Discord bots.

Connections. Spiritual successor to Heroku (after Salesforce hobbled Heroku's free tier). Often paired with Vercel (Next.js front, Railway back).

Usage
~1M developers; favorite for small teams with full-stack / Python back-ends
Niche
Heroku-replacement; full-stack indie
railway.comDocs

Render

Render · CEO Anurag Goel
PaaS

What it is. Direct Railway competitor. Same pitch — Heroku replacement, polyglot PaaS, git-push deploy. Slightly more enterprise-oriented.

What sets it apart. Strong background workers + cron jobs story. Predictable pricing. Long track record.

Connections. Often benchmarked head-to-head with Railway and Fly.io.

Usage
Widely adopted by small-to-mid teams
Niche
Same as Railway — it's largely a preference split
render.comDocs

Fly.io

Fly · CEO Kurt Mackey
EdgeRegion-aware

What it is. Runs full Docker containers (not just functions) at dozens of regions globally, with transparent region-based failover. Effectively edge-hosted Heroku.

What sets it apart. Unique "run a full app globally" primitive — Phoenix/Elixir + Fly is a cult favorite combo. Good fit for globally distributed AI chatbots.

Connections. Built heavily by ex-Heroku / Keen engineers. Popular among the Rails + Elixir crowd.

Usage
Smaller than Vercel/Netlify/Railway but deeply loved by its users
Niche
Globally distributed, stateful app deployment
fly.ioDocs

Cloudflare Workers / Pages

Cloudflare
Edge-serverlessUltra-cheap

What it is. Cloudflare's developer platform — Workers (V8-isolate serverless), Pages (static + Functions), R2 (S3-compatible object storage), D1 (SQLite), KV, Queues, Durable Objects.

What sets it apart. Runs at Cloudflare's edge (~300 cities) with effectively-free cold starts. Most generous free tier in the industry. Durable Objects give you stateful serverless — a genuinely novel primitive.

Connections. Cloudflare also ships Workers AI (see Cloud Platforms page). WebBot Auth protocol is co-developed with Anthropic.

Usage
Millions of Workers developers; growing AI-app share
Niche
Ultra-low-latency edge serverless; cheapest free tier

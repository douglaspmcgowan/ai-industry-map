Agent Runtimes / Terminals

A category that barely existed a year ago: terminals and environments purpose-built to run AI coding agents — Claude Code, Codex, Gemini CLI, Aider, OpenCode — rather than be them. Running one agent in a plain terminal is fine; running three in parallel exposes pain (which tab is waiting? which errored? which finished?) that these tools were built to fix.

Windows vs macOS. cmux — the tool that defined this category in early 2026 — is macOS-only. Windows users have two real options: Warp (cross-platform, AI-first) or Wmux (Windows-native clone of cmux's multi-agent pattern). Both are covered below.

cmux

manaflow-ai · launched Feb 2026 · AGPL
Open sourcemacOS only

What it is. A native macOS terminal built on Ghostty's libghostty rendering engine, designed specifically for running multiple AI coding agents in parallel. Vertical tabs, per-tab status lights (green = done, yellow = waiting for input, red = error), notifications when an agent finishes, a built-in browser for previewing changes, and a scriptable CLI/socket API.

What sets it apart. Defined the category. The status-light-per-tab metaphor is so obvious in hindsight that every subsequent "agent terminal" copied it. Free, open source, GPU-accelerated via Ghostty. Compatible with Claude Code, Codex, OpenCode, Gemini CLI, Kiro, Aider — any CLI tool.

Connections. Built on Ghostty (Mitchell Hashimoto's GPU terminal). Hit 7.7K stars in its first month. Inspired Wmux (the Windows port) and Calyx (another Ghostty-based competitor on macOS).

Wmux

Windows-native
WindowsMulti-agent

What it is. A Windows-first terminal multiplexer for AI coding agents. Orchestrate Claude Code, Codex, Gemini CLI across split terminals with smart notifications when an agent finishes or needs input. Ships with integrated browser automation via Chrome DevTools Protocol, so agents can drive a browser without a separate setup.

What sets it apart. Basically "cmux for Windows" — same philosophy, different OS. The browser-automation integration is a genuine add-on: if you have agents that need to test a web UI, you don't have to glue Playwright in yourself.

Connections. Aimed at the audience cmux explicitly excluded. The category's answer to "fine, but I'm on Windows."

Warp

Warp · founded 2020 · CEO Zach Lloyd
Cross-platformAI-first

What it is. A cross-platform (macOS / Linux / Windows) terminal rebuilt from scratch around AI. Inline agents that can plan, run, and review commands; block-based command history; collaborative sessions; integrated code editor. Not a dedicated "agent orchestrator" like cmux, but a full AI-native terminal that plays well with Claude Code and other CLIs.

What sets it apart. The most polished AI terminal, period. The only tool in this category with real Windows support — if you're on Windows and want a single "nice" terminal instead of stacking Warp + cmux-likes, this is it. Paid tiers for teams.

Connections. Predates the cmux-style category (Warp launched in 2022) and is now repositioned as "agent-first." Features Claude Code as a first-class integration on their site.

Yaw

yaw.sh
Claude Code–focused

What it is. A terminal purpose-built for Claude Code workflows. Watches for Claude Code launches and immediately opens a side-by-side layout: your AI agent on one side, a regular shell in the same project directory on the other.

What sets it apart. Narrower than cmux (Claude Code specifically, not "any agent") but nicer if that's all you use. The auto-split-on-launch ergonomics remove a manual tmux step.

Connections. Indie project. Part of the 2026 wave of "one terminal per agent type" experiments.

Niche
Claude Code power users who want a dedicated UI

Windows Terminal

Microsoft · open source
WindowsBaseline

What it is. The default modern terminal on Windows 11. Tabs, split panes, scrollback, search, PowerShell + CMD + WSL in one window. No AI-specific features.

What sets it apart. It's free, it's already installed, and it works fine for Claude Code / Codex / Aider. You have to set up split panes manually — there's no per-tab "agent status" indicator — but for a single agent at a time it's perfectly adequate.

Connections. The sensible fallback if you don't want to evaluate Warp or Wmux yet. Combine with WSL2 + Ghostty if you want the GPU-accelerated experience cmux users get on macOS.
